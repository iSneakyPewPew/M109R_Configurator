\# M109R Configurator



A browser-based proof of concept for visualizing and comparing aftermarket

modifications for the Suzuki Boulevard M109R.



\## Features



\- Interactive 3D viewer

\- Swap between stock and aftermarket components

\- Toggle accessories on/off

\- Runtime color changes

\- Built with Three.js and glTF assets



\## Status



This project is an early proof of concept and is under active development.
